# The Quad — Embed Guide

The Quad is The Stanford Daily's Connections-style game: find four groups of four.

## 1. Generate the embed code

Open [https://akhil-reddy-13.github.io/connections/generate.html](https://akhil-reddy-13.github.io/connections/generate.html) in any browser. Enter:

- **Puzzle #** — increment by one each day
- **Four groups**, easiest (yellow) to hardest (purple). Each group has a **category name** and **four items**. Every item must be unique across the puzzle.

Click **Generate Embed Code**, then **Open preview ↗** to play through it. Copy the iframe snippet.

## 2. Paste into WordPress

In your post, add a **Custom HTML** block and paste the iframe.

> **Note:** The Quad is hosted on a personal account for now. When the repo is transferred to TheStanfordDaily org, the site address becomes `https://thestanforddaily.github.io/connections/`. Update the link above, and regenerate any embeds made before the move.
